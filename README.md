# 九龍裝甲行動 · Kowloon Armor

適用於 Windows 的單人 3D 坦克遊戲，支援 USB 飛行搖桿／HOTAS、鍵盤及滑鼠。

## 開始遊戲

**毋須安裝遊戲、Node.js 或外掛。** 用 Windows 版 Edge 或 Chrome 開啟同一資料夾內的 **九龍裝甲行動.html**，即可離線遊玩。遊戲及素材已包含在這一個 HTML 檔案內，可獨立複製到其他位置。

亦可按兩下 **開啟遊戲.cmd**，以預設瀏覽器開啟遊戲。如預設瀏覽器不是 Edge／Chrome，請在 HTML 檔案上按右鍵，選「開啟方式」。首次開啟後，在車庫選坦克及模式，再按開始。

需要支援 WebGL 2 及已啟用圖形加速的瀏覽器。畫面較慢時，可在「遊戲設定」把畫面品質改為「流暢（關閉陰影）」。

## USB 飛行搖桿／HOTAS 設定

1. 先接駁搖桿和油門，確認 Windows 已辨識裝置。保持遊戲視窗在前景，**在每個裝置按一下按鈕**，讓瀏覽器偵測到它。
2. 在車庫按「HOTAS 控制設定」，或在遊戲內按 **H**。選擇「主要搖桿」；獨立油門可在「油門裝置」另選來源。「炮塔控制裝置」及「按鈕裝置」也可分開指定。
3. 查看「裝置即時訊號」，逐一推動各軸、按下按鈕，再把對應編號填入設定。**編號由 0 開始**；不使用的軸或按鈕填 **-1**。方向相反時勾選該軸的「反向」。
4. 會自動回中的搖桿選「置中搖桿：前進／後退」。獨立滑動油門選「滑動油門：零至全速」；此模式下，**按住倒車按鈕，再推油門才會倒車**，放開按鈕恢復前進方向。
5. 放開所有會回中的搖桿，滑動油門收至零，按「校準中立位置」。返回遊戲後，先把油門收至零，再推前，才會啟用行駛。每次重開遊戲、重新接駁或更改來源／軸設定後，請重新校準。
6. 如放手後仍有漂移，增加「中立死區」；如炮塔移動太快，降低「炮塔靈敏度」。預設死區為 **0.12**，靈敏度為 **1.00**。設定會自動儲存。

HOTAS 預設只是起點，實際軸號和按鈕號須以你的裝置即時訊號為準：

| 功能 | 預設 |
| --- | --- |
| 主要裝置 | 裝置 0；其餘來源使用主要搖桿 |
| 車身轉向／前進後退 | 軸 0／軸 1；前進後退軸已勾選反向 |
| 炮塔左右／炮管高低 | 軸 2／軸 3 |
| 開火／煞車 | 按鈕 0／按鈕 1 |
| 切換視角／按住瞄準鏡 | 按鈕 2／按鈕 3 |
| 按住倒車（滑動油門）／暫停 | 按鈕 4／按鈕 7 |

如果裝置未出現，先按裝置上的按鈕、返回遊戲視窗，再重新開啟控制設定。若 Windows 本身也未辨識，先處理 USB 連線或裝置驅動。**目前尚未以實體 USB HOTAS 完成測試**，不同廠牌的軸號、按鈕號和瀏覽器支援仍需在你的硬件上確認；鍵盤及滑鼠可隨時使用。

## 鍵盤及滑鼠

| 按鍵 | 功能 |
| --- | --- |
| W／S、A／D | 前進／倒車、車身轉向 |
| Q／E 或 ←／→ | 炮塔左右旋轉 |
| ↑／↓ | 炮管高低 |
| 按住滑鼠右鍵拖動 | 炮塔及炮管瞄準 |
| Space 或滑鼠左鍵 | 開炮 |
| B | 煞車 |
| 按住 Shift | 瞄準鏡 |
| V | 第三身／駕駛員／炮手視角 |
| Esc／H | 暫停／搖桿設定 |

三種模式均有無限備用炮彈，每次開炮仍需等待裝填。停車後較容易瞄準；炮塔可獨立於車身旋轉，建築物會擋住炮彈。

## 模式及內容

- **自由駕駛**：沒有敵軍，自由探索街道、練習轉向及射擊。
- **模擬對戰**：與四輛 AI 坦克進行單人演習。
- **九龍戰役**：六關逐步解鎖，依次為「初次出勤」、「路口封鎖」、「霓虹交鋒」、「海港防線」、「街區突圍」及「九龍終極演習」。敵軍由兩輛增至八輛，須在限時內完成目標。

闖關進度、勝場、最高分及控制設定儲存在目前瀏覽器的 **localStorage**，沒有雲端同步。清除瀏覽器資料、使用私人瀏覽、換瀏覽器或移動 HTML 檔案，可能無法沿用原有紀錄；瀏覽器拒絕儲存時，遊戲會顯示提示。

車庫提供 **30 款具代表性的現代坦克及原型車**，並非客觀的「全球最強」排名。原型車已標示；型號來源列於 `src/data/tanks.ts`。性能數值為遊戲平衡設定。坦克採用四個外形家族的程式生成模型，並非 30 款逐一精密重建的車體。

街道取材自油麻地、佐敦、旺角、尖沙咀及深水埗，以虛構九龍演習區呈現，路網經遊戲化重組。駕駛、慣性、煞車、炮塔及炮彈碰撞均採簡化模擬；畫面是原創瀏覽器遊戲設計，並非商業頂級坦克遊戲的同等製作規模。

## 開發及重新打包

一般遊玩只需 HTML。修改程式才需要 Node.js 及 pnpm；在本資料夾開啟終端機，執行：

```powershell
pnpm install
pnpm build
node scripts/serve.mjs
```

`pnpm build` 會先檢查 TypeScript，再產生 `dist/index.html` 及獨立的 `九龍裝甲行動.html`。預覽伺服器位址為 <http://127.0.0.1:4187>；在終端機按 Ctrl+C 停止。亦可執行 `pnpm dev` 使用開發伺服器。
