# 九龍裝甲行動 · Kowloon Armor

適用於 Windows 的單人 3D 坦克遊戲，支援 USB 飛行搖桿／HOTAS、鍵盤及滑鼠。

## 1.6 作戰工作台

[完整 30 項升級及驗收範圍](docs/operations-upgrade.md) · [1.6 驗收紀錄](docs/operations-validation.md)。保留 1.5 全部內容、原有戰役平衡及離線 HTML。

- **選車與練習**：車庫「整備工具」可收藏戰車、比較兩車、設定演習種子及三種選做挑戰；戰車目錄可只看收藏，或從篩選結果隨機選車。
- **戰術地圖**：戰鬥畫面按「戰術地圖」暫停查看實際障礙、敵軍、任務、最近 40 筆事件及戰況。點圖／填座標／選地標設定航點，抵達 10 米內自動清除。航點不是避障路線或自動駕駛。
- **射擊判讀**：射線對準可見敵車時顯示耐久、估算飛行時間、下墜及左右提前量。依遊戲炮速與當下勻速估算，不是命中保證，亦不會自動瞄準。極小視窗收起次要估算，保留主準星。
- **個人化**：可調追尾距離／視野、瞄準鏡滑鼠倍率、開炮震動、準星顏色／線條、低閃光，以及炮聲、引擎、提示音三項獨立音量。效能儀表預設關閉，顯示本機最近 120 個活躍畫面的中位／P95 幀時間及繪圖量。
- **戰後練習**：挑戰結算、針對性建議、相同配置重賽及本回合 JSON 戰報下載。戰報不是戰績備份；種子在相同版本／車型／模式／難度下重現初始配置，並非操作錄影。挑戰不加分，保甲須勝利，無盡防線宜選精準或機動。

收藏及舒適度設定存於目前瀏覽器；種子和挑戰選擇只保留到關閉／重載頁面。戰績 JSON 備份不包含種子、收藏或操作設定。沒有加入雲端、登入或外部素材。

```sh
npm run build
npm test
npm run test:operations
```

## 1.5 戰場判讀與九龍巡遊

十項改善：

1. **射線提示**：依炮管俯仰找最近可命中的部位，顯示正／側／後方及炮口遮擋。這是直線估算，遠距離仍須考慮彈道下墜。
2. **敵炮警戒**：敵車在 200 米內、視線暢通、炮塔對準你且裝填剩餘不超過一秒才提示。
3. **履帶修復狀態**：區分「須停車收油」及「修復中」，倒數與實際修復一致。
4. **六地標巡遊**：自由駕駛按「開始六站巡遊」，在街邊金圈內停穩兩秒簽到；可暫停／繼續，離開回合後重新開始。與基礎訓練分開。
5. **目的地導航**：巡遊下一站及戰役區域提供相對炮塔方向、距離及小地圖位置；不是自動導航或避障路線。
6. **戰後分析**：有效傷害、承受傷害、側後命中次數及行駛距離。有效傷害以實際扣除耐久計算，不包含溢出傷害；原分數公式不變。
7. **黃昏九龍**：設定 → 畫面可在日間／黃昏切換，調整天空、霧、暖色日光及補光，保留可讀視野。
8. **自動 3D 解像度**：設定 → 畫面可啟用，持續慢幀後逐級降至 60%，持續快幀後回升；文字不縮，暫停不取樣。預設關閉，不能代替降低 CPU／幾何負擔。
9. **夜間音效**：設定 → 聲音可啟用，降低輸出並壓縮動態；保留立體方位及裝填提示。預設關閉。
10. **高對比標記**：設定 → 畫面可啟用，琥珀敵軍菱形／青色我方箭頭，配合文字、受擊提示及目標圈。

沒有改動戰役勝負條件、車輛性能、HOTAS 校準或戰績格式。新設定可即時取消，舊設定自動補預設值。保留單檔離線及所有 1.4 街景。

新增驗證：`node scripts/field-check.mjs`、`node scripts/field-browser.mjs`。設計與驗收記錄見 [1.5 升級紀錄](docs/field-upgrade.md)。

## 1.4 九龍街景與戰場聲景

- **六個特色街廓**：尖沙咀鐘樓、油麻地舊警署、廟街牌樓、旺角市集、深水埗唐樓及西九 ICC，另有維港水面／對岸天際線。替換原有重複樓群，加入磚紋、風化外牆、露台、竹棚、冷氣機及燈籠。簡報與小地圖有地標位置；自由駕駛可穿過旺角及深水埗的中央小巷，攤檔仍可阻擋炮彈。鐘樓及廟街是封閉架高街廓。
- **全部敵車外觀更新**：30 車共用依車重／口徑劃分的突擊、側襲、支援識別構件（裝甲塊、天線或格柵與條紋）。這是裝備外觀分類，AI 仍沿用 1.2 的分路、掩護及撤退系統；沒有新加步兵或平民。低耐久與殘骸有煙霧、焦黑，修復後還原塗裝；煙霧固定 128 粒上限。
- **原創聲音**：炮聲低頻／瞬態、聲音傳播延遲、距離與方向、建築遮擋及街谷回響；履帶噪音隨速度改變。低音、打擊與音列配樂按敵軍距離及受擊調整密度，配樂音量可獨立關閉，總音量同時控制兩者。暫停／返回車庫停止戰場聲景。

保留單檔離線、30 車、六關、四模式、HOTAS 和舊戰績。地標按香港旅發局資料作原創風格化重建，位置／比例經遊戲化處理，**不是實景掃描或等比例九龍地圖**。聲音參考大型坦克遊戲的分層／動態方法，沒有取用其音樂、錄音或模型。[資料來源、設計及驗證](docs/hong-kong-upgrade.md)。

```sh
npm run build
npm test
npm run test:hong-kong
```

`test:hong-kong` 包括來源場景截圖、戰鬥取樣、Web Audio 離線音訊渲染，以及正式 HTML 的音樂設定、三種視窗、開火及暫停。音訊峰值檢查不等於真人耳機／喇叭聽感驗收；Windows 顯示卡及實體 HOTAS 仍須實機測試。

## 1.3 出擊整備更新

- **清楚的出擊流程**：戰車仍是畫面主角；任務、難度及出擊集中在獨立整備列，修正低高度視窗遮住開始按鈕的問題。簡報提供實際路網、目標、時限和敵軍位置；選車、模式及關卡會保留。
- **容易找到的設定**：畫面、操作、聲音、戰績四頁，支援鍵盤分頁、可見焦點及固定關閉按鈕。戰車目錄可搜尋、按車重篩選及性能排序。
- **可靠的本機戰績**：JSON 匯出、驗證與預覽後合併；保留較佳進度及分數，不會重複累加勝場。主紀錄損壞時讀取上一次有效副本，儲存失敗有明確提示。
- **完成整個回合**：可選四步實際駕駛訓練、離開演習確認、任務倒數與耐久警戒，以及顯示上次紀錄、失敗原因和下一步的戰後報告。

保留下列 1.2 戰術系統、30 車、四模式、六關、HOTAS 及單檔離線；沒有加入帳戶、付費項目或連線依賴。

## 1.2 戰術更新

- **可靠射擊**：正／側／後裝甲按炮彈來向判定，不受開炮後轉炮塔影響。車體、炮塔、左右履帶分開命中；履帶受損限制機動，停車累積六秒修復。
- **分工敵軍**：側路包抄後推進、裝填找掩護、低耐久短暫撤退；難度亦改變反應與炮塔速度。尋路預留車身淨空，不只檢查中心線。
- **不同任務**：六關加入佔領路口及守區；無盡防線波間可選修復或四發快裝補給，而非單純重複清場。
- **可調操作**：16 項鍵盤功能可改鍵／恢復預設；C 獨立觀察、瞄準鏡按住或切換、2／3／4 倍鏡、HUD 大小。滑鼠位移跨渲染幀保存，固定物理步進才消耗。
- **原創細節**：四款代表車增加識別構件，左右履帶差速；街區地標、方向／受擊／任務提示、有上限的煙塵、空間炮聲與裝填完成提示。保留 30 車、四模式、舊紀錄及單檔離線。

## 開始遊戲

**毋須安裝遊戲、Node.js 或外掛。** 用 Windows 版 Edge 或 Chrome 開啟同一資料夾內的 **九龍裝甲行動.html**，即可離線遊玩。遊戲及素材已包含在這一個 HTML 檔案內，可獨立複製到其他位置。

亦可按兩下 **開啟遊戲.cmd**，以預設瀏覽器開啟遊戲。如預設瀏覽器不是 Edge／Chrome，請在 HTML 檔案上按右鍵，選「開啟方式」。首次開啟後，在車庫選坦克、模式及難度，再按右下方的琥珀色開始按鈕；想先了解目標可開啟任務簡報。新手可選「先練習操作」，實際完成行駛、停車、轉炮塔和開炮四步，不影響戰役解鎖。

需要支援 WebGL 2 及已啟用圖形加速的瀏覽器。畫面較慢時，可在「遊戲設定」把畫面品質改為「流暢（關閉陰影）」。

## USB 飛行搖桿／HOTAS 設定

1. 先接駁搖桿和油門，確認 Windows 已辨識裝置。保持遊戲視窗在前景，**在每個裝置按一下按鈕**，讓瀏覽器偵測到它。
2. 在車庫按「HOTAS 控制設定」，或在遊戲內按 **H**。選擇「主要搖桿」；獨立油門可在「油門裝置」另選來源。「炮塔控制裝置」及「按鈕裝置」也可分開指定。
3. 查看「裝置即時訊號」，逐一推動各軸、按下按鈕，再把對應編號填入設定。**編號由 0 開始**；不使用的軸或按鈕填 **-1**。方向相反時勾選該軸的「反向」。
4. 會自動回中的搖桿選「置中搖桿：前進／後退」。獨立滑動油門選「滑動油門：零至全速」；此模式下，**按住倒車按鈕，再推油門才會倒車**，放開按鈕恢復前進方向。
5. 放開所有會回中的搖桿，滑動油門收至零，按「校準中立位置」。返回遊戲後，先把油門收至零，再推前，才會啟用行駛。每次重開遊戲、重新接駁或更改來源／軸設定後，請重新校準。
6. 如放手後仍有漂移，增加「中立死區」；如炮塔移動太快，降低「炮塔靈敏度」。預設死區為 **0.12**，靈敏度為 **1.00**。設定會自動儲存。

HOTAS 預設只是起點，實際軸號和按鈕號須以你的裝置即時訊號為準：

| 功能 | 預設 |
| --- | --- |
| 主要裝置 | 裝置 0；其餘來源使用主要搖桿 |
| 車身轉向／前進後退 | 軸 0／軸 1；前進後退軸已勾選反向 |
| 炮塔左右／炮管高低 | 軸 2／軸 3 |
| 開火／煞車 | 按鈕 0／按鈕 1 |
| 切換視角／按住瞄準鏡 | 按鈕 2／按鈕 3 |
| 按住倒車（滑動油門）／暫停 | 按鈕 4／按鈕 7 |

如果裝置未出現，先按裝置上的按鈕、返回遊戲視窗，再重新開啟控制設定。若 Windows 本身也未辨識，先處理 USB 連線或裝置驅動。**目前尚未以實體 USB HOTAS 完成測試**，不同廠牌的軸號、按鈕號和瀏覽器支援仍需在你的硬件上確認；鍵盤及滑鼠可隨時使用。

## 鍵盤及滑鼠

| 按鍵 | 功能 |
| --- | --- |
| W／S、A／D | 前進／倒車、車身轉向 |
| Q／E 或 ←／→ | 炮塔左右旋轉 |
| ↑／↓ | 炮管高低 |
| 按住滑鼠右鍵拖動 | 炮塔及炮管瞄準 |
| M | 鎖定／釋放滑鼠瞄準；釋放時暫停 |
| F | 炮塔回正至車頭、炮管回到水平 |
| Space 或滑鼠左鍵 | 開炮 |
| B | 煞車 |
| 按住 Shift | 瞄準鏡 |
| 按住 C | 獨立觀察，保持炮塔方向 |
| V | 第三身／駕駛員／炮手視角 |
| Esc／H | 暫停／搖桿設定 |

四種模式均有無限備用炮彈，每次開炮仍需等待裝填。停車後較容易瞄準；炮塔可獨立於車身旋轉，建築物會擋住炮彈。滑鼠鎖定需要瀏覽器允許；如未能鎖定，仍可用右鍵拖動。按 Esc、切換視窗或斷開搖桿會暫停。

表內為預設鍵位；「遊戲設定 → 操作 → 鍵盤按鍵設定」可更改 16 項功能，重複的鍵會交換，Esc 固定為暫停。設定分畫面、操作、聲音、戰績四頁，分頁可用左右方向鍵／Home／End 切換；可調滑鼠靈敏度（0.3–2.5 倍）、垂直反向、減少動態效果、音量、畫質、HUD 85／100／115%、瞄準鏡 2／3／4 倍及按住／切換。HOTAS 瞄準鏡仍為按住。小視窗限制 HUD 放大，避免遮擋。設定儲存在目前瀏覽器，重新開啟仍會沿用。

車重會影響加速、煞車、原地轉向及炮塔速度。單側履帶受損時機動降至 28%，兩側為 14%；停穩後，放開油門或按住煞車，修復倒數才會前進。HUD 會顯示受損側和秒數。命中方位／部位均為遊戲化判定，並非真實裝甲穿透模型。

## 模式及內容

- **自由駕駛**：沒有敵軍，自由探索街道、練習轉向及射擊。
- **模擬對戰**：與四輛 AI 坦克進行單人演習，每次出擊更換敵軍車型及安全出生位置。
- **九龍戰役**：六關逐步解鎖。第 1／3 關清場；第 2／5 關在標示路口累積佔領 20／30 秒；第 4／6 關守區 45／60 秒。佔點與守區都須人在區內且沒有敵車爭奪才計時；守區每被爭奪一秒損失 8% 防線，降至零失守。敵軍全滅不能代替到場，守區亦不必全滅敵軍。車體損毀或超時同樣失敗。
- **無盡防線**：首波兩輛敵車，每波增加一輛，最多八輛；敵軍耐久和傷害逐步提升並有上限。清場後有 8 秒整備時間，可選「修復 35% 最大車體耐久及兩側履帶」或「四發快裝炮彈：每次裝填時間 ×0.68」。預設修復，倒數結束只結算一次；快裝用完回復正常，不能同時回血。可在暫停選單返回車庫；主動離開的回合不記錄成績。

入門／標準／精英的敵軍耐久倍率為 0.75／1／1.35，敵軍傷害倍率為 0.6／1／1.4，得分倍率為 0.75／1／1.5；戰術反應間隔為 1.1／0.75／0.4 秒，炮塔追蹤速度為 0.45／0.65／0.9 rad/s。難度不改變所選戰車的性能。戰役進度沿用原有存檔；最高分按難度分開，舊版關卡最高分仍會顯示在戰役地圖。

闖關進度、勝場、最高分及控制設定儲存在目前瀏覽器的 **localStorage**，沒有雲端同步。清除瀏覽器資料、使用私人瀏覽、換瀏覽器或移動 HTML 檔案，可能無法沿用原有紀錄；瀏覽器拒絕儲存時，遊戲會顯示提示。

### 備份及搬移戰績

在車庫按「戰績」，或開啟「遊戲設定 → 戰績」，選「匯出戰績備份」。搬移 HTML、清除網站資料或更換瀏覽器前，先保存下載的 JSON。新位置選取備份後會先顯示預覽，確認才合併；進度、勝場及各項最高分分別取較高值，重複匯入不會增加勝場。檔案上限 64 KB，只接受本遊戲版本 1 格式，格式或儲存失敗不會套用匯入。

備份包含戰績及基礎訓練完成狀態，**不包含操作設定或 HOTAS 校準**；新裝置仍須自行設定及校準。瀏覽器內的上一次有效副本只用於主紀錄損壞時救回，不能代替外部備份。暫停選單的「返回車庫」須再次確認；主動結束未完成演習不記錄成績。

車庫提供 **30 款具代表性的現代坦克及原型車**，並非客觀的「全球最強」排名。原型車已標示；型號來源列於 `src/data/tanks.ts`。性能數值為遊戲平衡設定。坦克採用四個外形家族的程式生成模型；Leopard 2 A8、M1A2 Abrams SEPv3、T-90M、Merkava Mk4 Barak 有額外外形構件，仍非 30 款逐一精密重建的車體。

街道取材自油麻地、佐敦、旺角、尖沙咀及深水埗，以虛構九龍演習區呈現，路網經遊戲化重組。駕駛、慣性、煞車、炮塔及炮彈碰撞均採簡化模擬；畫面是原創瀏覽器遊戲設計，並非商業頂級坦克遊戲的同等製作規模。

## 開發及重新打包

一般遊玩只需 HTML。修改程式才需要 Node.js 及 pnpm；在本資料夾開啟終端機，執行：

```powershell
pnpm install
pnpm build
node scripts/serve.mjs
```

`pnpm build` 會先檢查 TypeScript，再產生 `dist/index.html` 及獨立的 `九龍裝甲行動.html`。預覽伺服器位址為 <http://127.0.0.1:4187>；在終端機按 Ctrl+C 停止。亦可執行 `pnpm dev` 使用開發伺服器。

## 驗證

```sh
pnpm test
pnpm exec playwright install chromium
pnpm test:browser
pnpm benchmark current
```

`test` 包含原有模擬、波次、難度、全城出生點、存檔與渲染批次，以及彈道／命中部位、30／60／144 Hz 輸入、履帶、AI 分工、目標成功／失敗／重試、補給和資源上限回歸；另驗證戰績備份／救回／合併、拒絕儲存、偏好驗證、訓練順序，及完整城市六關輸入式自動駕駛。`test:browser` 直接以離線 `file://` 開啟成品，以實際點擊驗證短視窗佈局、四步訓練、分頁／改鍵、真正下載、檔案預覽／取消／合併、失敗提示、操控、首關勝利及解鎖；獨立測試頁使用同一套 Game／Input／Interface／View，加速驗證新目標、補給、真實受擊失敗／重試、合成 HOTAS、雙視窗及 20 分鐘固定步進作戰。沒有在正式成品注入測試接口。瀏覽器證據與效能原始數據放在 `.omo/evidence/`（不提交）；版本報告另保存精選證據。原有 Windows Edge QA 腳本 `scripts/qa.mjs` 仍可在已安裝 Edge 的環境使用。

效能測試記錄 1280×800、DPR 1、平衡／流暢畫質的 WebGL 提交量及 frame time，另保留有敵軍與爆炸的樣本、資源與 heap 觀察。20 分鐘模擬不是 20 分鐘連續實時渲染；軟件繪圖結果不能換算成 Windows 顯示卡的幀率。測試範圍及結果見 [1.3 驗證紀錄](docs/deployment-validation.md)；[1.2](docs/tactical-validation.md)及 [1.1](docs/release-validation.md)紀錄另行保留。
