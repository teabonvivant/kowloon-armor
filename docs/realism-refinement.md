## 效能結果與限制

Chromium 141.0.7390.37／SwiftShader；1280×800、DPR 1、medium，固定駕駛鏡位。兩個保留的來源測試頁依次測，暖機 4 幀後各 12 幀；每幀完整模擬、render、`gl.finish` 及同步 `readPixels`，未攔截 draw call。這是小樣本軟件渲染比較，不能推算 Windows／手機 FPS。

| 指標 | 上一輪樣板 | 本輪 |
| --- | ---: | ---: |
| 中位同步渲染 | 1703.2 ms | 1134.1 ms |
| P95 | 1757.0 ms | 1251.4 ms |
| 繪圖呼叫 | 129 | 150 |
| 三角形 | 157,688 | 204,720 |
| 已渲染幾何／紋理 | 12／24 | 14／29 |

本次中位時間降低約 **33.4%**，但幾何與 draw call 增加。不能把這組結果當成全部設備均提升 33.4%，也未精確分離各 shader 改動貢獻。

最終完整渲染圖片已用圖像工具查看：街景、車首／車尾、店舖、手機橫向及矮視窗整備。成品操作套件使用手動 rAF、每批只繪製末幀；只證明功能與版面，不是實時流暢度。發射機構圖與黃昏圖來自來源測試頁，非正常速度錄影片段。本輪沒有製作新影片。

初輪整批命令在回傳功能通過後收到 SIGTERM（退出 143），原因未確定；未將其算作整批完成。後續凍結版本的瀏覽器與完整渲染比較分開執行，均退出 0。
