# 1.7 觸控與清晰視野：50 項改善

基準 e8720af，2026-10-13。獨立執行。沿用 TypeScript、Three.js、單檔離線及原有傷害／戰役／HOTAS。今輪以可操作的觸控介面取代手機縮小桌面 HUD；不是新增 50 種玩法。狀態：50 項實作及本機驗收完成。證據見 [驗證紀錄](touch-validation.md)。

## 設計與驗收清單

1. 粗指標裝置自動顯示觸控控制，不以螢幕寬度冒充裝置種類。
2. 有觸控但有滑鼠的混合裝置，首次觸碰自動切換。
3. 設定可指定自動／觸控／鍵鼠，保留外接裝置選擇。
4. 平板橫向寬螢幕仍保留觸控。
5. 左側虛擬搖桿前進／倒車。
6. 搖桿左右控制車身，支援同時轉彎前進。
7. 搖桿採比例輸入，短推可慢駛。
8. 中心死區防止微小手震令車漂移。
9. 超出搖桿範圍時輸入限制於合法範圍。
10. 搖桿指示點隨手指移動，放手回中。
11. 手指移出搖桿仍能控制，放手解除。
12. 右側場景拖動獨立瞄準。
13. 觸碰場景不會意外開炮。
14. 多指可同時駕駛、瞄準、開炮。
15. 每根手指擁有自己的操作，不互相搶佔。
16. 獨立大開火鍵，按住可依原裝填規則連射；快速點按亦保留至下一次物理更新，不會漏炮。
17. 開火鍵顯示裝填時間及就緒。
18. 開火鍵用環形進度表示裝填。
19. 瞄準鏡單按切換，有啟用狀態。
20. 觸控瞄準有獨立靈敏度。
21. 觸控瞄準鏡降低靈敏度，沿用倍率設定。
22. 觸控垂直反向可獨立設定。
23. 獨立煞車按鍵。
24. 可選放開搖桿自動煞車。
25. 觸控可切換三種視角。
26. 觸控可炮塔回正。
27. 觸控可切換獨立觀察，離開時回復瞄準。
28. 暫停／地圖／設定清除所有按住操作。
29. 來電式失焦／隱藏頁面清除操作並暫停。
30. pointercancel／失去指標捕捉解除相應操作。
31. 旋轉裝置時暫停並清除輸入，避免移位誤駕。
32. 戰鬥區停用拖頁和選字，設定頁保留捲動及縮放。
33. 控制區避開瀏海及底部手勢安全區。
34. 左右手佈局可交換並保存。
35. 觸控按鍵至少 44px，主開火鍵更大。
36. 預設精簡 HUD，亦可選詳細模式。
37. 手機／平板觸控始終使用精簡 HUD，詳細戰況仍可在地圖查看。
38. 移除戰鬥常駐鍵盤教學列，指南移到暫停選單。
39. 精簡模式收起小地圖，以一鍵暫停大地圖代替。
40. 移除重複彈種／無限彈藥卡，保留裝填提示。
41. 耐久改為短列及進度條，隱藏常駐車名卡。
42. 精簡速度讀數，不再用大字佔據車尾。
43. 任務改成頂部短列，區域進度及失守提示仍可見。
44. 目標詳細彈道估算移至詳細 HUD；主準星仍保留命中／遮擋。
45. 敵軍標記只保留距離及耐久，收起長車名。
46. 修復／嚴重受損才顯示損傷文字，正常狀態不佔位。
47. 教學按實際控制方式改寫提示，精簡卡不蓋中央。
48. 巡遊和補給卡採邊緣短列，避免壓住駕駛／開火區。
49. 手機橫直向、矮視窗、平板及桌面分別驗證，保留按鍵焦點與減少動態。
50. 新觸控設定嚴格驗證、向後相容並保存；重開回合不累積控制器或監聽器。
