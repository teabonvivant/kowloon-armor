# 九龍裝甲行動：寫實戰場重製設計

狀態：使用者已批准設計及執行；獨立可玩樣板、影音及本輪驗證已交付，待使用者觀感驗收。尚未發布取代正式版，量測所得效能回退仍是推廣關卡。日期：2026-10-15。
基線：v1.8，提交 `80e4ac5`。本文件是新一輪重製的設計入口，不代表前輪功能清單已達到美術標準。

## 目標與決策

使用者要求品牌識別、可信戰場、真實炮彈及後座，並要求先討論再優化。已由兩位明確指定 `gpt-6-astra/max` 的獨立評審分別檢查射擊與視覺，主代理整合；不把主對話未核實的思考強度當成 MAX。

建議方向：寫實射擊，配合克制的軍事電影光影。香港街區、裝甲重量、作戰整備是品牌主題。品質目標是逐段拿實玩畫面比較，不以功能數量、測試數量或自評分數代替觀感。

替代方向：全日光軍事紀實更利於辨識，但需要更高品質模型與材質才能成立；強烈電影爆破更直接刺激，但不能用放大火球及搖鏡代替真實後座。

先完成一個可玩的品質樣板：Leopard 2 A8、出生點前方茶餐廳／藥房街口約 100 米及一次完整交火。此為整體重製的第一驗收點，不是把全遊戲升級縮減為單一場景。樣板通過觀感驗收後才把共用系統及美術規格擴展至其他車型與街區。

## 已核實問題

| 問題 | 證據 | 後果 |
| --- | --- | --- |
| APFSDS 名稱與慢速彈道不符 | `src/combat.ts` 固定初速 190、重力 1.2；`src/operations.ts` 重複同一常數 | 炮彈像可追蹤的慢速光彈，不能只換外形 |
| 炮口與物理起點分離 | `combat.ts` 使用車身加 5.5 米，畫面用 0.08 秒 offset 淡出 | 彈體顯示位置與碰撞位置不一致 |
| 地面碰撞未與其他接觸取最近點 | 射擊評審以 60 Hz、俯角 −0.12 探針重現：先穿地，再在 y=−0.035 回報建築命中 | 提高彈速前必須一起比較地面、牆壁及車輛接觸比例 |
| 機構沒有分離 | `render/tank.ts` 炮盾與炮管同屬後座群組 | 整個炮口基座一起滑動，缺乏可信機械結構 |
| 車身反應與鏡頭各自套曲線 | `render/tank.ts` 的 bounce、`effect-math.ts` 的 cameraKick | 缺少同一發射事件及受力方向的完整時序 |
| 城市過於規律 | `render/world.ts` 固定網格、`geo-buildings.ts` 重複窗格；預設畫質實際截圖 | 城市像整齊模型，缺少戰場構圖與事件痕跡 |
| 材質層次有限 | `render/materials.ts`、`tank-details.ts`、`view.ts` | 裝甲、建築與道路質感分離不足 |
| 品牌以產品目錄為主 | `DESIGN.md`、`garage.ts`；預設畫質車庫實際截圖 | 有選車介面，但沒有完整作戰整備身份 |

## 重製範圍

### 射擊與機械

- 炮盾／搖架固定，炮管及相應後座部件沿炮軸運動；快速後退、受控復位，車體只作有限且方向正確的懸掛反應。
- 修正前射時車頭先低的初始俯仰，以及開炮瞬間把既有行車俯仰清零的跳變；以方向及連續性測試驗收，不靠加大搖鏡。
- 統一炮口位置、炮口方向、物理初始狀態、曳光及命中位置。非等比例車身縮放不能扭曲炮彈方向。
- 建立有來源的炮／彈組合資料，不能把一個型號數值套給全部 30 車。沒有可靠資料的車型明確採遊戲化參數。
- 一起修改飛行時間、重力、HUD 提前量與敵軍射擊。以連續掃掠碰撞防止高速彈穿牆；重測近距離炮口障礙及移動目標。
- 取消持續煙尾的火箭觀感。使用克制短暫曳光；近距離不刻意慢放讓玩家看清彈體。裝甲命中、混凝土碎屑、地面塵土和擊毀分別表現。
- 新速度會改變戰鬥體驗，需重測六關難度；不能沿用「完全不改平衡」的舊承諾。

### 視覺與品牌

- 先用灰材質驗證車體輪廓、接地與主光，再處理漆甲、裸鋼、橡膠、瀝青的粗糙度及高光差異。
- 樣板車優先修正比例、炮塔／炮盾、輪組與履帶輪廓；不能靠新增小方塊取代模型品質。
- 樣板街口安排清楚的前、中、遠景；招牌、外牆、街道磨損服務構圖。戰損集中在交火位置，不在全城隨機撒碎片。
- 建立一致的中文字標、部隊識別、克制琥珀提示及整備場景。車庫、HUD、戰報使用同一套圖形語言。
- 保留手機中央視野，觸控鍵與危險提示優先；煙塵、鏡頭震動及閃光均保留舒適度控制。

### 聲音

- 同一發射事件驅動炮口瞬態、低頻衝擊、炮閂機械及街谷尾響；車內／車外、近／遠及遮擋分開處理。
- 真實錄音僅在來源及授權可核對時採用；程序音效不得標作實錄。不得複製商業遊戲受保護音效或配樂。
- 驗收需要可播放的前後聲音片段及聽感比較，峰值／靜音測試只證明技術條件。

## 驗收門檻

1. 同鏡位、同畫質、同車型拍攝前後對照；另錄完整行駛、停車、轉炮塔、開炮、命中、裝填片段。慢動作只用來檢查機構，另交正常速度。
2. 前、側、斜向及不同俯仰的射擊：固定炮盾不滑移；炮管沿軸後退；車身反應與炮向一致；物理起點等於視覺炮口。
3. 高速彈在 30／60／144 Hz 輸入與固定物理步進下，對近牆、遠牆及移動目標的命中一致；HUD 使用相同彈道資料。
4. 關閉 HUD 與煙霧仍能看出材質、重量與場景主次；不得靠煙霧遮住低品質模型。
5. 桌面、矮視窗、手機與平板都實際操作；保留多指、暫停、設定、舊戰績、離線及 HOTAS 模擬回歸。
6. 以相同指定設備與完整渲染路線記錄中位／P95 幀時間、繪圖量及資源回收。軟件 WebGL 不代表玩家設備效能。
7. 樣板需使用者確認觀感方向。單元測試或代理評分不能替代這一點；未經驗證不得稱已達 AAA／大廠水準。
