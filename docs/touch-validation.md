## 實際限制

- 伺服器 Linux Chromium／SwiftShader；觸控為瀏覽器模擬，不是 iPhone、Android、iPad 或 Safari 實機。
- 20 分鐘是固定步進模擬時間，不是持續 20 分鐘的實機 60 FPS 遊玩。沒有新增實機幀率宣稱。
- 實體 HOTAS、手機系統手勢、真實瀏海安全區、行動瀏覽器音訊中斷／恢復、長時間溫度及耗電尚未實機驗證。
- 舊版地標／音樂等內容沿用；本輪沒有新增素材或複製商業遊戲資產。

設計覆核參照 [Web Interface Guidelines](https://github.com/vercel-labs/web-interface-guidelines/blob/main/command.md)：觸控區域、標籤、焦點、減少動態、安全區及模態捲動；沒有停用整個網站的縮放。
