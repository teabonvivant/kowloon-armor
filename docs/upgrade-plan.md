# 九龍裝甲行動改良計劃

以現有 Three.js／TypeScript 與離線 HTML 為基礎，所有改動直接在同一專案完成。

- [x] 基線：TypeScript、九項模擬測試、固定 viewport 的 Chromium 截圖與 WebGL 提交量／frame time。
- [x] 核心：先以測試界定難度、生存波次、安全出生點、整備回血及分難度本地紀錄，再接上 Game 與介面。
- [x] 操控：可儲存畫質、音量、滑鼠靈敏度、反向與鎖定瞄準；暫停、失焦、離開鎖定時清除輸入。
- [x] 視覺：車庫層次／出擊摘要、實際方位羅盤、命中回饋、HUD 波次／成績；塗裝細節、車身配件、路邊設施及道路磨損。
- [x] 效能：城市按區塊剔除、靜態矩陣、批次輪組、減少熱路徑配置及 HUD 重建；相同基準重測。
- [x] 驗證：模擬、離線瀏覽器實際操作、不同視窗、設定／紀錄重載、零外部資源、建置及改動 review。

驗證方法、數據、畫面及限制集中在 [版本驗證紀錄](release-validation.md)。GitHub 推送後另核對本地及遠端提交 SHA、離線成品 blob SHA。

視覺方向：既有 #111719 炭灰／#e8a65a 琥珀／#84c7b0 薄荷，模型展示及炮手視線優先，標題保留中文重量，數字採 Bahnschrift。保留四種家族及 30 車；新配件與城市物件全部程序生成。
