# 1.2 戰術升級：設計、執行及驗收

日期：2026-10-11。基準：`8ed3961`，已 fetch，與 origin/main 相同；工作目錄原本乾淨。

## 已批准的範圍

沿用 Three.js、TypeScript、固定 60 Hz 物理及本地存檔。保留 30 車、四模式、六關逐關解鎖、HOTAS 及單檔離線。選擇在現有架構加入可讀的戰術規則；單純調高敵軍數值不足以解決體驗，完整軍事模擬及護送尋路則超出這次範圍。所有性能仍為遊戲設定。

- 射擊：以飛行方向判斷正／側／後裝甲，連續掃描車體、炮塔及左右履帶。履帶命中降低車體傷害、限制機動；停車累計六秒修復，畫面顯示剩餘時間。
- 輸入：只在實際物理步進消耗滑鼠位移及按鍵邊沿；鼠移為位移量，鍵盤／HOTAS 為速度量。驗證 30／60／144 Hz。
- AI：沿路網分工包抄、裝填找掩護、低耐久短暫撤退；難度改變反應及炮塔速度。首關保留教學節奏。
- 任務：第 1／3 關清場，第 2／5 關佔點，第 4／6 關守區。佔點要到達指定地點且無敵軍爭奪；守區要守滿時間，敵軍進區會扣防線耐久；清場不能跳過新目標。
- 生存：八秒整備期間選擇修復車體 35% 及履帶，或四發裝填時間減少 32% 的補給；預設修復，只結算一次。
- 操作：可改鍵及恢復預設、按住 C 獨立觀察、瞄準鏡按住／切換與 2／3／4 倍、HUD 大小。車重影響加速、煞車、轉向與炮塔速度。
- 畫面及聲音：四款代表車增加識別構件，左右履帶差速；街區地標及名稱、任務環、有數量上限的煙塵；炮聲距離衰減與左右聲像，裝填完成與部位命中提示。

## 驗收及預算

新增機制以行為測試及真實 Game 固定步進驗證，UI 的離線產品遊玩與加速測試頁分開標示。保留既有測試，因規則改變而更新斷言必須解釋。HOTAS 用合成 Gamepad 驗證；不聲稱已試 Windows 或實體裝置。

離線成品零網絡素材請求；新增套件為零。單檔目標小於 1.5 MB。坦克履帶增加最多每車一個 draw；煙塵 96 粒、爆炸同時上限 20 組。相同場景比較基準／新版，WebGL 提交量目標增幅不超過 25%；如戰鬥中的目標數不同則單列。保留敵軍／炮火／爆炸樣本，觀察至少三分鐘或等效多輪任務的資源穩定性。SwiftShader frame time 只用於這個環境，不當作實機 FPS。

## 已知界限

護送、多人、外部美術素材、完整真實裝甲穿透／彈種、可破壞城市不在此次範圍。角色模型仍採四個程序化家族，代表車獨有構件不等於 30 車精密重建。
