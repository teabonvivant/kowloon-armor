# 1.3 出擊整備：設計、執行及驗收

日期：2026-10-12。基準：`b0beeb3`，乾淨 main。沿用既有 Three.js／TypeScript、原創程序模型、30 車、四模式、六關戰役、HOTAS、舊紀錄及單檔離線。

## 設計決定

香港鍵盤／滑鼠／HOTAS 玩家在桌面電腦進行演習，車輛和街景仍是主體。沿用炭灰 `#111719`、深灰 `#090d0f`、面板 `#161e21`、文字 `#f2f2e9`、琥珀 `#e8a65a`、薄荷 `#84c7b0`；離線系統中文字體、Bahnschrift 數值。平穩、清晰、低動態，資訊密度適中。

比較單純改色、重寫引擎及完整出擊流程後，採用第三項。特色是固定在戰車展示下方的出擊列，把任務、難度和開始按鈕放在同一條視線；模式與車輛資訊在有界的左右欄，戰車庫獨立佔一行。短視窗先精簡次要資訊，極短時只讓資訊欄捲動，不能再壓住出擊或戰車庫。手機可瀏覽／設定，沒有觸控駕駛宣稱。

- 車庫顯示實際任務條件、時間、敵數和逐關進度；完整簡報可按需開啟。保留快捷開始，記住選車、模式和關卡。
- 設定分畫面、操作、聲音及戰績四頁，原生 tab 語意、方向鍵／Home／End、固定關閉位置。子頁有返回，結束遊戲時離開確認避免誤觸丟失回合。
- 戰績匯出版本化 JSON；匯入先嚴格驗證、預覽，再合併各項較佳數值。重複匯入不累加勝場，不下降進度；只包含戰績，操作設定與 HOTAS 校準不跨裝置搬移。最近有效戰績副本可救回損壞主紀錄；明確顯示讀取／寫入失敗。
- 自由駕駛加入可選的四步實際操作訓練：行駛 15 米、停穩、獨立轉炮塔、開炮。須順序實作，暫停不推進，開新局重設；完成後繼續自由探索。
- 戰後報告顯示實際任務結果、上一紀錄與差距、針對失敗原因的建議及下一關／重試。HUD 明確顯示耐久警戒、剩餘時間、目標狀態。

## 技能及檢查

使用 brainstorming／writing-plans 整理方案，按已授權任務直接執行。impeccable context 在專案目錄讀到 PRODUCT／DESIGN，採 product register。frontend-design 以真實戰車與出擊列建立階層；taste-skill 僅採與既有產品重設相關部分，沒有改成營銷頁。ui-ux-pro-max 檢查焦點、表單、錯誤及返回路徑；emil-design-eng 將狀態轉場限於短促 opacity／transform、保留減少動態；web-design-guidelines 使用 2026-10-12 讀取的官方規則。

browser-act core 回報無配置瀏覽器；沿用專案的 Playwright Chromium、隔離暫存 profile，直接開啟離線成品，不接管私人瀏覽器。

## 驗收界限

不新增依賴、帳戶、商店或多人服務；不聲稱商業認證、AAA 美術、實體 HOTAS／Windows 驗收或軟件繪圖等同實機 FPS。匯入非可信資料不得插入 HTML、不得執行程式，格式／大小錯誤不能改寫現有紀錄。效能比較限定同一環境及場景。
