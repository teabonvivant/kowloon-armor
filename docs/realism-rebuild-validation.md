# 寫實方向樣板：驗證與交付

本文件為第一輪歷史紀錄。本機樣板已在第二輪更新；目前範圍、成品雜湊及驗收請看 [第二輪清單](realism-refinement.md)。第一輪圖片／影音保留，不能當作第二輪測試結果。

日期：2026-10-15。狀態：獨立可玩樣板、影音與本輪驗證已交付；**尚未取得使用者觀感驗收、未發布或取代正式版**。軟件渲染效能回退列為後續關卡，並非已完成效能驗收。

## 開啟成品

- 遊戲：專案根目錄 `九龍裝甲行動-寫實樣板.html`，可用支援 WebGL 2 的桌面瀏覽器離線開啟。
- 對照／影音入口：`docs/evidence/realism/index.html`。
- 「街口交火」有兩輛 AI 敵車及勝負結算；「自由試車」沒有敵軍。原有四步訓練、設定、舒適度、觸控與 HOTAS 設定保留。
- 鍵鼠：WASD 駕駛、B 煞車、Q/E 轉炮塔、右鍵拖曳瞄準、Space 開炮、Esc 暫停；手機可同時駕駛、拖曳瞄準及按住開火。
- 正式版 `九龍裝甲行動.html` 沒有改動。樣板使用獨立進度／備援鍵 `kowloon-armor-realism-progress` 及獨立設定鍵；訓練、匯入與重設亦不會寫入正式版進度。HOTAS 校準繼續使用原有設定。

## 實際改動

1. **射擊鏈條**：炮口、發射方向、實際炮管軸、炮焰與炮聲位置共用同一轉換；非等比根節點縮放不再令炮軸偏斜。L55／DM63A1 使用 1,720 m/s、重力 9.81 m/s²；HUD 與 AI 使用同一資料。AI 同時考慮車體俯仰／側傾及炮口隨轉炮而改變的位置。
2. **近距離及高速碰撞**：炮膛至炮口與第一段飛行一起選取最近接觸；近敵車不會因炮口已越過碰撞盒而被跳過。地面、不同高度障礙及車輛接觸共同排序。取消樣板炮彈持續煙尾。
3. **機械**：固定炮盾／搖架，只有炮管群組沿炮軸後座；開炮不清除行車俯仰。前射有限抬頭、側射方向相符的側傾；鏡頭讀取同一發射時鐘。減少動態設定保留。
4. **視覺方向**：重新製作楔形炮塔、車體輪廓、輪組、光學件、機艙及分材質表面；手工安排茶餐廳／藥房街口、參差樓高、側牆、店面、簷篷、管線、修補路面及交火處損壞。新中文字標／徽章、作戰整備及克制琥珀介面。
5. **原創音效**：炮口瞬態、低頻壓力、炮閂與復位聲、街谷尾響；保留距離／聲速延遲／遮擋，增加車內外分別。獨立審核發現滿音量混音削波後，樣板輸出加入 20% 餘量；正式版輸出不變。

初速來源：[Rheinmetall 120 mm system house，DM63A1／L55，第 6 頁](https://www.rheinmetall.com/Rheinmetall%20Group/brochure-download/Weapon-Ammmunition/B195e0423-Rheinmetall-120mm-system-house.pdf#page=6)。這是該炮／彈組合的參考，不聲稱所有 Leopard 2 A8 實際配彈都相同，也沒有把數值套用其餘 29 車。

## 畫面及錄影方法

- `before-drive-clean.png`／`after-drive-clean.png` 與 `before-garage-clean.png`／`after-garage-clean.png`：1440×900、DPR 1、medium、相同出生位置／鏡位，隱藏 HUD／提示，沒有煙霧遮住模型。基線測試頁在修改前保存，不以新場景假冒基線。
- `artifact-garage-*`／`artifact-play-*`：真正離線成品。操作測試使用手動 rAF 時鐘、每批只完整繪製末幀，**這批操作截圖不是正常速度錄影或效能證據**。初版測試時鐘早於啟動，已修正並重拍；觸控取消及關閉對話框亦等待真實事件送達。
- 正常時間軸影片已以 12 fps、768×432 完整逐格渲染，固定 1/60 秒模擬。低幀率是軟件渲染環境的擷取取捨，不是聲稱遊戲只支援 12 fps，亦不代表實時 60 fps。音軌按相同發射／接觸／裝填事件時間渲染，沒有挪用別款遊戲錄音。已抽看 3.58 秒命中、20.15 秒交戰及 43 秒結算畫面。
- 影片與無 HUD 對照來自保留的來源測試頁，在最後「移除全城地標／試車標籤」修正前擷取；影片沒有打開地圖，該修正不改模型、街景、物理或音訊。最終獨立 HTML 在修正後重建並重跑五種尺寸，**不把來源影片冒充最終 HTML 的實時錄屏**。
- 聲音前後對照：原版 5 秒、空白 1 秒、樣板 5 秒；相同 master 0.7、120 mm、引擎／音樂關閉，沒有正規化。數值通過不代表真人聽感較好，仍需使用者試聽。
- `gameplay-timeline.json` 的 `renderMilliseconds` 只量渲染呼叫／提交，不包含阻塞影像讀回，不能用來推算 FPS。下列效能量測另使用阻塞讀回，避免只量到命令提交。

## 效能：明確回退，尚未通過推廣關卡

相同容器、Chromium 141.0.7390.37、SwiftShader、1280×800、DPR 1、medium、固定駕駛鏡位；依次測基線及樣板。各暖機 4 幀後記錄 20 幀，完整 Game update／Three.js render／`gl.finish`／阻塞 `readPixels`，無 HUD、無繪圖呼叫攔截。原始紀錄為 `evidence/realism/benchmark.json`。

| | 基線 | 樣板 |
| --- | ---: | ---: |
| 中位完整渲染＋同步 | 1,148.0 ms | 1,753.2 ms |
| P95 | 1,402.9 ms | 2,169.9 ms |
| 繪圖呼叫 | 164 | 129 |
| 三角形 | 352,794 | 157,688 |
| 已渲染幾何／紋理 | 10／27 | 12／24 |

**樣板中位數約慢 53%，不是效能提升。** 幾何／呼叫量下降不代表材質與著色器成本下降；本輪沒有完成 GPU profiling，不能把全部差額精確歸因某個 shader。此同步讀回量測包含同步成本、不含 HUD 合成或輸入延遲，亦不能代表其他硬件 FPS。需先處理材質／渲染成本、再以真實裝置驗證，才可擴展全遊戲；本輪不繼續另一個長時間最佳化循環。

## 明確限制與下一個關卡

- **這是可玩的方向樣板，不是 AAA／商業大作完成品。** 車體及街道仍看得出程序化幾何、重複立面和材質近看限制，轉往街口側面會看到簡化的場景邊界；程序音效亦不等於現場錄音。
- 沒有空氣阻力、精密穿甲、實物懸掛或完整火控穩定器模擬。裝甲／傷害／裝填及敵軍決策仍屬遊戲化；樣板只有兩輛對手，沒有完成六關新彈速平衡。
- 最後收尾已移除樣板中不存在的全城地標／捷徑，地圖保留實際障礙、敵我及座標航點，並標明街口樣板；自由試車不提供原全城六站巡遊入口。它仍是簡化戰術圖，不是精密實景地圖。
- 未驗證真實 iPhone／Android／iPad、Safari、Windows GPU、實體 HOTAS、耳機／喇叭聽感或硬件音訊延遲。瀏覽器尺寸模擬不能替代這些驗收。
- 主代理已看過前後與實際成品截圖，並獨立複驗射擊修正；**使用者觀感確認仍未完成**。未 commit、push 或部署。確認方向後才擴展其他車型／街區，並安排六關難度及實機驗證。

## 重現

```sh
npm run build:realism
node scripts/realism-check.mjs
node scripts/realism-preview.mjs
node scripts/realism-browser.mjs
node scripts/realism-audio-review.mjs
node scripts/realism-evidence.mjs
node scripts/realism-audio-review.mjs --timeline docs/evidence/realism/gameplay-timeline.json --timeline-only
ffmpeg -y -i docs/evidence/realism/gameplay-silent.mp4 -i docs/evidence/realism/audio-gameplay.wav -c:v copy -c:a aac -b:a 192k -movflags +faststart -shortest docs/evidence/realism/gameplay.mp4
node scripts/realism-benchmark.mjs
```

`realism-baseline.mjs` 僅用於保留本輪基線，不應在換掉正式版後重新執行並覆蓋舊證據。所有測試頁接口只在證據 harness；分發成品不含它們。
